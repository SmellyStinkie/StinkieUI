# Stinkie UI 0.39.0

Flat PvP UI for WoW: Midnight (12.1.5, Interface 120105) and WoW Forever (Interface 16001), from one build: unit, party, arena and battleground frames, nameplates, castbars, class resource bar, cooldown bars, chat, minimap and more. No library dependencies.

## Install
Works on retail (Midnight) and WoW Forever. Forever has no arena, so the arena frames stay off there; the character sheet doesn't mark missing enchants on Forever yet (its enchantable slots aren't mapped).
Unzip so the folders are `World of Warcraft/_retail_/Interface/AddOns/StinkieUI/` and `.../AddOns/StinkieUI_History/` (each `.toc` directly inside its folder). The release zip already has both. If you install from the source code, move the `StinkieUI_History` folder out of `StinkieUI` so it sits next to it; it's the Match History window and only loads when you open it.
**Fully exit and restart WoW after installing or updating** whenever the Media folder gains files (0.17.0 replaces the logo files). WoW only picks up new files on a full restart, not on `/reload`.

## Commands
- `/stinkie`, `/st` or `/sui`: options window (also in the addon compartment and Options > AddOns)
- `/rl`: reload the UI
- `/stinkie dmg`: which damage-number settings this game version has, and their values.
- `/stinkie cpu`: measures Stinkie UI's CPU use for 30 seconds and prints the busiest parts.
- `/stinkie unlock` / `/stinkie lock`: move frames. Drag a box, or click it and use the arrow keys (Shift = 10px). A panel shows its exact X/Y. Every options page also has anchor, X and Y fields with nudge buttons.
- `/mh` (or `/matchhistory`, `/st m`, `/st mh`): Match History window; `/mh stats` opens the Match Stats tab; `/mh import` imports Rated Tracker's history (Rated Tracker must be enabled that session)
- `/stinkie flags`: what the game reports about flags and learned cap spots (Flag Cap Indicator); `/stinkie flags reset` relearns the current map
- `/stinkie score`: what the battleground score bar holds right now (Match History's final score)
- `/stinkie timers`: map name and base icons as the game reports them (for adding BG Timers maps)
- `/stinkie fontcheck`: prints how the client loads each font (for troubleshooting)
- `/stinkie plates`: prints the nameplate stacking settings this game version has
- `/stinkie auras`: prints how your target's nameplate aura icons are set up (for bug reports)
- `/stinkie quest`: what the Quest marker can see right now (for bug reports)
- `/stinkie reset`: restore all defaults and reload

## What's in it
- **Font**: one font for everything, including Blizzard's own UI (tooltips, buff timers, spec names, character sheet, damage meter, zone text, settings), names above characters (relog) and optionally floating combat text (relog); PT Sans Narrow Bold by default. Every text (names, health, castbars, nameplates, class resource, cooldown counts) has its own size, outline and color, and names can be class colored.
- **Unit frames**: player, target, target of target, focus, pet, and optional party targets (a small frame per party member's target, lined up with the party frames; blank and hidden in arenas and battlegrounds, where Blizzard blocks them). Flat class-colored health, optional power bar, name inside or above, health text (default %), absorb overlay (shields can be turned off per frame). Target and focus show your debuffs, CC and major defensives. Target and focus also get one big crowd-control icon beside the frame. The small aura icons can be turned off while keeping the big CC icon. Names can show first, last or both, with an option to show level; party, party targets and arena frames have the same options.
- **Health bars**: dark gray empty area, yellow shield after current health, and an overshield (shield bigger than missing health) drawn backwards over the top half so it never needs extra room. New target/focus snaps to the right value instead of filling up.
- **Party**: arena-frame style (test mode shows a tank, a healer and two damage dealers, in range and casting) with a resizable green healer cross. PvP trinket and defensives on one side, crowd control (bigger, optional glow) on the other, dispellable debuffs in a row below or after the CC. Target border, range fade, power for all / healers / none. Test mode. Hidden in battlegrounds and Blitz by default. Optional target marker.
- **PvP Assist**: Big Debuffs (crowd control, major defensives and offensive cooldowns shown big and glowing to the right of enemy nameplates), a movable, resizable "Healer in CC!" warning with the CC icon (optional sound), your Precognition (or any buffs you list) big and glowing, and an enemy interrupt tracker that shows who kicked you or a teammate with a cooldown timer. Glow options for party CC and trinkets. Test mode.
- **Minimap**: round or square, border on/off, fonts for the zone name, clock and coordinates, coordinates moved where you like, buttons shown / on mouseover / hidden, auto-hide in arena, battlegrounds, Mythic+ and raids. On a square map the zone bar and calendar sit centered right on top of it, the mail icon goes in a corner, and the Omnium Folio button sits in another corner.
- **Castbars**: player, target, focus. Float by default; each can attach to its frame. Colors for interruptible, not interruptible and interrupted are configurable. Also a flat look for Blizzard's melee, off-hand and ranged swing timers on WoW Forever, with an option to show them only while attacking.
- **Class resource**: soul shards (Destruction shows partial shards), combo points, holy power, chi, arcane charges, essence. Flat segmented bar with 1px lines between segments, optional number in the middle, class default or your own color. Floats, or attaches above the player frame.
- **Nameplates**: enemies get health, level, name (above, or inside the bar), castbar, your debuffs, all CC and big/external defensives. Debuffs can be all, Blizzard's important ones, or a whitelist, plus a blacklist. Target highlight with thickness, size, color and optional `> <` arrows. Toggles for enemy pets, guardians, totems and trivial units (these switch Blizzard's own settings directly). Important totems and Psyfiend turn pink, draw on top and get a bigger click area. Elite/boss star. Friendlies get a small class-colored name (above or on the bar) and a thin health line. Healers get a green (friendly) or red (enemy) cross, sized as you like; outside groups healers are found by inspecting nearby players, out of combat. In arena, the enemy healer cross comes from Blizzard's own secure spec helper. Flag / orb carriers get a big icon above the plate (size up to 120). In Blitz the enemy healer cross also tries Blizzard's role helper and the scoreboard role. Optional spec icons above enemy and/or friendly players: left or right of the healer cross, or centered with the cross beside or above it, with X/Y offsets. Long names can be capped at a number of characters. Healer cross up to 100 px. Blizzard's quest / interact icon is enlarged and moved above the plate; friendly plates can be lowered. Enemy pets / guardians / totems / trivial units are set from Stinkie UI's boxes (pets and totems on by default). Target markers above the plate, and names can show first, last or both.
- **Action bars**: restyles Blizzard's bars to match the cooldown skin (zoomed icons, 1px edge), hides the bar art, macro names on or off, keybinds on or off, cooldown numbers on or off with their own size, and per-bar show-on-mouseover. Layout stays in Edit Mode. Off automatically if Bartender, Dominos or ElvUI is loaded. The bag bar and menu icons can be set to show on mouseover too. Lock buttons option, and keybinds that show only on the bar under the mouse.
- **Chat**: restyles Blizzard's chat windows: flat background and tabs (color and opacity for each), font, size, outline and message spacing, wrapped-line indent. Messages come back after a `/reload` and after your next login, then drop off (or reloads only, or off). Copy window (button on mouseover) and optional drag-to-copy. Timestamps (none, HH:MM, HH:MM:SS; 12 or 24 hour) in the line or in their own column, in their own color. Short or name-only channel tags, brackets removed, realm names hidden, sender level, class-colored names, "From Name:" whispers, a color for every chat type and channel. New whispers in their own tab, tabs flash on new messages, and the whole chat can stay hidden until you mouse over it. Off automatically if Chattynator, Prat or ElvUI is loaded.
- **Miscellaneous**: GCD History, a strip of the spells you just cast that slides along as you cast more (size, count, direction, time on screen, always / in combat / PvP only, interrupted casts in red, ignore list, test button, movable). Auto-Confirm Decor Purchases: buying housing decor from a vendor skips the confirmation popup, with an optional gold limit. Also auto accept and turn in quests, repair, sell junk, release in battlegrounds and hide red error messages, all off by default.
- **Cursor**: Blizzard's cursor size, plus an optional ring around the cursor (size, thin/thick, color, opacity, combat only).
- **Cooldowns**: optional square flat skin for Blizzard's Cooldown Manager (icons and buff bars), plus row centering. Two custom bars for spells, items, trinkets, racial and Healthstone. In options the bar shows as icons: drag to reorder, right-click to remove. Drop spells or items on the box to add them. Hover any icon and press your ping key to ping it. Spells you haven't learned (or that aren't in your current spec) and items you have none of are left off the bar.

- **Arena frames**: health, healer power bar, castbar, spec icon, green healer cross (size and corner), resizable teammate-target squares (bright green by default, or class colors), trinket, DRs (pick categories, or Blizzard's 'only DRs I can apply'), one square per teammate who is targeting that enemy, and a border on your own target (thickness and color). Test mode in options, and automatically while unlocked. Right click focuses by default (or target / menu / nothing). They turn themselves off if sArena or Gladius is running. Names are cleared between games and Solo Shuffle rounds.
- **Combat indicator**: icon on the player frame or anywhere, plus an "Entering / Leaving Combat" message that can be moved and styled.
- **Battleground frames** (Blitz and 10-15 player battlegrounds; off in 40-player ones): one block for the enemy team and one for yours, each titled Horde / Alliance, sorted healers, tanks, then damage. Allies always have live health and range. Flag / orb debuff with its stack count next to the carrier icon. Enemies: every enemy's name and class color from the scoreboard, click a row to target (right click focuses by default), flag/orb carrier icon (left or right), spec icon (learned before the gates open, class icon otherwise), live health / dead / out-of-range fading for enemies you can see. Test mode in options and while unlocked. Thick target highlight (thickness and color). Tank shield next to the healer cross. In live matches (Blitz) where Blizzard hides spec and role, the spec shows as text and the role still shows as a cross or shield (drawn with two tiny bundled symbol fonts, display-only). Enemies out of sight keep their last known health, faded. The icon beside each row shows the role: green cross for healers on both teams, shield for tanks, sword for damage (or the spec / class icon if you prefer, or when the role isn't known). Name and spec text are left-aligned and centered together, each with its own size. Horde / Alliance titles are centered over the icons and bars together. Carriers get crisp flag (red / blue) and orb (bright color) icons. Optional mana strip along the bottom of healer rows (or everyone), live while that player is visible. Optional buffs beside each ally, or only the ones you cast.
- **Healer crosses** everywhere (nameplates, party, arena, battlegrounds) have a thin black outline. Green on party, arena and battleground frames; red only above enemy nameplates.
- **Look**: the options window carries the Stinkie logo and its colors (fel green, hood plum, warm black, orange trim); the logo is also the addon-list and compartment icon.
- **Profiles**: every character uses Default until you give it its own profile (General page). Copy settings between profiles, delete old ones, and export / import a profile as a string.
- **Battleground score**: move and resize the score display at the top and the cart / capture progress widgets, and restyle the score bars (Blizzard, flat, or any shared-media texture; Alliance and Horde colors). Only inside battlegrounds. Test mode shows stand-ins so you can place and style them anywhere. The Return to Graveyard button can be moved and resized too.
- **Flag Cap Indicator** (BG Score page): in Warsong Gulch and Twin Peaks, a banner per flag that's out, under the score display (or anywhere, any size): the flag, the carrier's name (class colored), yards to their cap spot, and ON CAP (flashing) / NOT ON CAP / DROPPED. Optional seconds-until-cap. Cap spots are learned from where each flag is picked up and remembered per map.
- **BG Timers**: bars for assaulted bases (per-map capture time, editable), the predicted winner and final score of resource battlegrounds (from both teams' live score rates), and the next resurrection wave while you're dead. Each type can be turned off. Movable and styled like the rest.
- **Match History** (`/mh`): every rated arena, Solo Shuffle, Blitz and rated BG is saved at the end (skirmishes, brawls and unrated games optional): result (Shuffle rounds), rating and MMR before and after, team and enemy MMR, map, length, your spec, hero talents, PvP talents, talent loadout and item level, and every player's full scoreboard line including the map's own stats. Browse and filter (bracket, character, your spec, season, period, result, player or map search; click any stats column heading to sort), queue time per match (only the time you were waiting outside other matches), and open any match's full scoreboard. **Match Stats**: win rate with a 95% range by map, enemy comp, enemy spec, your team comp, teammate, opponent, faction (battlegrounds), your spec, hero talents, enemy MMR, match length, time of day and day of week; rating trend, streaks, best / worst map; CSV export. The window is a separate load-on-demand addon, so history costs no memory until you open it. One-click import of your Rated Tracker history (about 10,000 matches take a few seconds and end up around 6 MB on disk).
- **Queue Time & MMR**: while you're queued, each queue's bracket, time waited, Blizzard's estimated wait and your MMR there with the change from your last game (+73 green / -40 red; Solo Shuffle and Blitz per spec), taken from your last match since the game only shows MMR at the end of a match. The spec icon you're queued as on each queue, an optional "Queued as" line, "MMR unknown, play a game" until you have a match there. Four equal columns (bracket, time, estimate, MMR); N/A where the game gives no MMR. Hidden while you're in an arena or battleground. Movable, resizable, with an optional background.
- **Character Sheet**: on your character window and when inspecting others: each item's name or upgrade track (e.g. Mythic 6/6, track-colored), item level, PvP item level for gear that scales in PvP, gem icons including empty sockets, and enchants (a green check, or a red cross for a missing enchant on helm, shoulders, chest, legs, boots, rings and weapons). Compact by default: set names dropped (Gladiator's Amulet -> Amulet), names capped, C1/6-style tracks, weapon text under the weapons. Background behind the model: any warband camp, flat dark, Blizzard's, or any texture / atlas, with darkening. Hover a stat to highlight its row and the items that have it. Stats Blizzard hides at 0 (and movement speed) are added under the list, unless you choose to hide them. Flat equipment-set buttons and side tabs. Item level to two decimals, plus overall and PvP. Flat look (no frame art, portrait or gradients, 1px borders, quality-colored item borders), and both windows can be made bigger with a size slider or the drag corner.
- **Window Skins**: the Character Sheet's flat look on Friends / Social, Group Finder and PvP, Adventure Guide, Warband Collections, Achievements, Guild and Communities, Professions, Housing Dashboard, and the Game Menu background; each window is restyled once when it first opens. Bags, talents / spellbook and the map are left alone (protected).
- **Tooltip**: size; at the mouse with X / Y offsets (default +128 / +25), at a fixed spot you drag, or Blizzard's spot; hide unit tooltips or all tooltips in combat (Shift shows them); health bar on / off; the unit's target (class colored, YOU in red); guild rank for your guild and others; class-colored names; spell and item IDs.
- **Buff frame**: Blizzard's buff and debuff icons with zoomed icons, a 1px border and your fonts for duration and stacks; hidden in arenas and battlegrounds by default (also dungeons, raids, in combat or always; debuffs optional), back on mouseover.
- **Arena / Solo Shuffle info**: Blizzard's top-center round and timer display gets its own position, size and the Stinkie UI font.
- **Objectives**: font sizes and outline for the quest tracker, scale, flat headers and progress bars (no gradients), optional background (0% opacity by default), hidden in arenas, battlegrounds and raids (and optionally Mythic+ / dungeons). Also the Quest marker: a small nameplate in the world on the quest you're tracking, with its distance in yards, that shrinks with distance and points the way when it's off screen.
- **Window Mover** (replaces BlizzMove): drag Blizzard's windows (character, spellbook and talents, collections, group finder, map, bags, mail, vendors, professions, auction house, Great Vault and more) by any empty part, and Ctrl + mouse wheel over one to resize it. Positions and sizes are remembered and re-applied whenever a window opens. Alt + right-click resets a window. Off while BlizzMove is enabled.
- **Damage meter**: restyles Blizzard's built-in damage meter to match: flat bars (or any shared-media texture) with a 1px edge, flat header (your color and opacity) and background, your font with separate name / number / header styles, zoomed icons, optional hidden scroll bar. Size, bar height, class colors and opacity stay in Edit Mode.
- **Combat logging**: automatic `/combatlog` in arena, Solo Shuffle, Blitz, regular battlegrounds, Mythic+, other dungeons and raids (separate toggles), with Advanced Combat Logging turned on for you. It stops when you leave, turns back on after a `/reload` inside a match, and never stops logging you started yourself. Optional "one log for the whole session": once on, logging stays on until logout so every match lands in one file.

Settings marked `*` need a reload.

## Midnight limits (Blizzard rules, not bugs)
- Battlegrounds: no DR data reaches addons. Health and range only exist for enemies you can see; when Blizzard hides a name, a row links up only if that class+race is unique on the enemy team. Trinkets aren't available there either.
- Arena: trinkets and DRs come from Blizzard's own arena widgets, which Stinkie UI moves into its frames. DR category picking only works when Blizzard reveals the category; if it's hidden in rated games, every category shows.
- Arena: enemy roles are hidden in rated games, so the healer-only power bar falls back to mana users there.
- Target of target and party targets can't show anything inside arenas or battlegrounds. Addons are blocked from compound units like `targettarget` and `party1target` in PvP matches.
- Battleground chat ("X has assaulted the Mine") is hidden from addons during matches, so BG Timers read base states from the map icons, and each map's capture time has to be set (Arathi Basin, Battle for Gilneas and Deepwind Gorge come at 60 s).
- Flag cap spots aren't exposed by the game; the Flag Cap Indicator learns them the first time each flag is picked up on a map.
- Health, power, casts and auras are "secret values" in combat and PvP. They can be displayed but not computed on.
- Friendly nameplates inside dungeons and raids are locked by Blizzard and stay default.
- Important totem coloring matches by unit name or NPC ID. Where Blizzard hides those from addons, the totem stays normal colored. Which of two overlapping plates gets the click is Blizzard's call; a bigger click area only helps where plates don't overlap.
- Enemy healer crosses on nameplates only appear where the game tells addons who is a healer: battleground scoreboard specs (learned before the gates open) and inspectable players. In arena and for most open-world enemies it can't know.
- Teammates' cooldown timers (other than the PvP trinket) aren't available to addons in Midnight; their big and external defensives show while active.
- The cursor image itself can't be recolored by addons; the ring is the colored option.
- Chat inside arenas, battlegrounds, dungeons and raids reaches addons hidden. Those lines still get timestamps and Blizzard's class colors, but they keep Blizzard's wording, can't be saved for after a reload and show as "(hidden)" in the copy window.
- Chat wrapped lines use the game's own indent; addons can't set its width.
- Death Knight runes and aura-based resources (Devourer, Icicles, Maelstrom Weapon) aren't on the class resource bar yet.
